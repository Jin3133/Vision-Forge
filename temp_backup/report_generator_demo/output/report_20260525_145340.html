SAM_ViT_B 农业遥感语义分割微调实验报告

实验背景与目标

本实验基于 SAM (Segment Anything Model) 的 ViT-B 版本进行农业遥感图像语义分割任务的微调。Agriculture-Vision 2024 数据集包含玉米、大豆、小麦三种作物在三期（早期、中期、晚期）的高分辨率遥感影像，覆盖多时相、多光谱的复杂农田场景。实验旨在验证预训练视觉大模型在遥感领域下游任务中的迁移能力，并系统性地探索不同微调策略（全参数微调、部分微调、LoRA）对分割精度的影响。

实验配置分析

模型选择 SAM_ViT_B 的核心考量在于其参数规模（89M）在精度与效率之间取得了良好平衡。相较于 SAM_ViT_H（256M 参数），ViT-B 的训练时间仅需 2.25 小时，推理延迟仅 22ms，更适用于实际部署。数据集 Agriculture-Vision 2024 的多时相特性对模型的时间泛化能力提出挑战，训练时采用 1024×1024 的高分辨率输入以保留遥感影像中的细粒度农田边界信息。训练策略方面，采用 AdamW 优化器配合 CosineAnnealingLR 学习率调度，设置 5 个 epoch 的 warmup 以稳定初期训练，weight_decay 为 0.01 以控制过拟合，总共训练 50 个 epoch，batch_size 为 8。

核心发现与实验结论

实验结果表明，全参数微调的 SAM_ViT_B 在 Agriculture-Vision 2024 数据集上取得了 0.72 的 mIoU，相较于未微调的 Baseline（0.41）提升了 31 个百分点。消融实验进一步揭示：仅微调 Mask Decoder 或 Prompt Encoder 分别达到 0.58 和 0.63 的 mIoU，说明 Prompt Encoder 在遥感场景中的适应性贡献更大。LoRA（rank=8）以 0.68 的 mIoU 接近全参数微调效果，同时显著降低训练开销。添加 Efficient Attention 机制后 mIoU 提升至 0.74，验证了注意力优化对遥感分割任务的有效性。在推理效率方面，SAM_ViT_B 以 45 FPS 和 22ms 延迟优于 SAM_ViT_H（28 FPS / 35ms），略低于 GroundingDINO（52 FPS / 19ms），但分割精度显著领先后者。

实验总结

SAM_ViT_B 在 Agriculture-Vision 2024 农业遥感分割任务中，全参数微调后 mIoU 达 0.72，LoRA 微调以更低成本达到 0.68，添加 Efficient Attention 进一步提升至 0.74。模型在 45 FPS / 22ms 延迟下兼具精度与效率，适合实际农业遥感部署。Prompt Encoder 的微调收益（+0.22）高于 Mask Decoder（+0.17），表明遥感场景中的提示编码适应性是关键优化方向。—— SAM 农业遥感微调实验总结

后续优化建议

建议后续尝试：1) 增加 SAM_ViT_H 的 LoRA 微调以逼近其 0.78 上限；2) 引入多光谱通道适配层以充分利用遥感影像的多波段信息；3) 探索 prompt 工程（如地理坐标编码）进一步提升 Prompt Encoder 的迁移效果。
