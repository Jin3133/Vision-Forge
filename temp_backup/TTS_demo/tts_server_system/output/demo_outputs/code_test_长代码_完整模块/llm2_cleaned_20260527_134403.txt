我来为您创建一个完整的数据库连接池模块，包含您要求的所有功能。

这是一个数据库连接池模块，支持连接池管理、查询执行、事务处理和性能监控。模块导入了必要的库，包括时间、线程、队列、日志记录、上下文管理、数据类、类型提示、枚举和SQLite数据库。

首先配置了日志系统，设置了信息级别和输出格式。然后定义了连接状态枚举，包括空闲、活跃、已关闭和错误四种状态。

接下来定义了连接信息数据类，包含连接对象、创建时间、最后使用时间、状态、查询计数和错误计数。还定义了查询统计信息数据类，包含查询次数、总时间、错误次数和慢查询列表。

模块定义了数据库操作异常和连接池异常两个自定义异常类。

性能监控器类用于记录查询性能数据，包含慢查询阈值、统计字典和线程锁。它可以记录每次查询的类型、持续时间和是否成功，并生成性能统计报告，包括平均时间、错误次数和最近的慢查询记录。

数据库连接池主类包含完整的连接池管理功能。初始化时需要指定数据库路径、最小连接数、最大连接数、超时时间、空闲超时、最大重试次数和慢查询阈值。

连接池内部使用队列管理空闲连接，使用字典记录活跃连接，并通过线程锁和条件变量保证线程安全。初始化时会创建最小数量的连接，并启动一个维护线程定期检查连接状态。

创建连接的方法会设置WAL日志模式和外部键约束。获取连接时会从队列中获取，如果连接无效则重新创建。
