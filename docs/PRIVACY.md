# 隐私政策

**最后更新日期：2025 年 7 月**

## 1. 信息收集

### 1.1 您主动提供的信息

- **注册信息**：姓名、用户名、学号、专业（存储在本地浏览器 localStorage 和项目 SQLite 数据库中）
- **学习数据**：学习目标、知识掌握度、模型配置、对话记录
- **评估反馈**：模型工坊评估结果、6 维学习画像数据

### 1.2 自动收集的信息

- **使用数据**：页面访问记录、功能使用频率、学习时长统计
- **设备信息**：浏览器类型、操作系统版本

## 2. 信息使用

我们收集的信息用于：

- 提供个性化学习体验和教学建议
- 生成 6 维学习画像和能力评估报告
- 生成定制化学习资源（讲义、练习题等）
- 改进平台功能和用户体验

## 3. 信息存储

3.1 用户数据存储在以下位置：

- **浏览器本地存储（localStorage/sessionStorage）**：认证 Token、学习状态、用户偏好
- **项目 SQLite 数据库**：用户账户信息、学习材料记录
- **黑板状态数据库**：会话上下文和智能体交互记录

3.2 所有数据存储在用户本地设备或项目部署服务器上，**不会上传到第三方云服务**（大语言模型 API 调用除外，见第 4 节）。

## 4. 第三方服务

### 4.1 大语言模型 API

本平台使用**讯飞星火大模型 API**（`spark-api-open.xf-yun.com`）进行智能对话和内容生成。发送到 API 的数据包括：

- 用户的学习目标和知识水平
- 模型架构配置信息
- 会话历史记录

这些数据仅用于本次 API 调用，我们不会将数据用于其他目的。数据在传输过程中经过加密。

### 4.2 其他可能使用的 API

- DeepSeek API（`api.deepseek.com`）
- 智谱 ChatGLM API（`open.bigmodel.cn`）
- Moonshot Kimi API（`api.moonshot.cn`）

这些 API 仅在用户主动选择对应模型时调用，且仅发送必要的对话内容。

## 5. 数据安全

5.1 密码使用 bcrypt 哈希存储（或明文存储，取决于当前版本配置状态）。

5.2 我们采取合理的技术手段保护用户数据安全，但不能保证绝对的安全性。

5.3 建议用户不要在对话中发送敏感个人信息（如身份证号、银行卡号等）。

## 6. 用户权利

您有权：

- 访问和查看您的个人数据
- 更正不准确的个人信息
- 删除您的账户和相关数据
- 导出您的学习数据

如需行使上述权利，请通过 GitHub Issues 联系我们。

## 7. Cookie 和本地存储

本平台使用浏览器的 localStorage 和 sessionStorage 存储以下数据：

- 认证 Token（`mock_token`）
- 学习状态（`vf_learn_state_v2`）
- 用户偏好设置

这些数据仅在您的浏览器本地存储，不会通过 Cookie 传输到服务器。

## 8. 政策更新

我们可能会不定期更新本隐私政策。更新后的政策将在本页面公布，重大变更将通过平台通知用户。
