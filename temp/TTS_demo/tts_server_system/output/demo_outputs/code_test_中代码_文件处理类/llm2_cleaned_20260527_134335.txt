我来创建一个完整的配置文件管理类，包含所有要求的功能。

这个类叫做ConfigManager，是一个配置文件管理类，支持JSON和YAML格式的配置文件读写。它包含异常处理、日志记录和类型检查功能。

在初始化方法中，需要传入配置文件路径和日志级别，默认日志级别为INFO。初始化时会设置日志记录器，创建控制台处理器，并设置日志格式。

加载配置文件的方法会检查文件是否存在，根据文件扩展名选择解析方法。如果是JSON格式就使用json.load，如果是YAML格式就使用yaml.safe_load。如果文件不存在或格式不支持，会记录错误并返回False。

保存配置的方法会根据文件扩展名选择保存方法，将配置数据写入文件。JSON格式使用json.dump，YAML格式使用yaml.dump。

获取配置项的方法支持点号分隔的嵌套键，比如可以传入database.host这样的键名。如果键不存在，可以返回指定的默认值。
