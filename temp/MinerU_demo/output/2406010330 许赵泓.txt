6.2 卡诺图化简法
化简步骤： 1. 画出对应变量数的卡诺图 2. 将函数填入卡诺图（最小项填1，无关项填×） 3. 圈出相邻的1（圈的大小为 ） 4. 每个圈写一个乘积项 5. 将所有乘积项相加得最简与或式
圈选原则： - 圈越大越好（消去的变量越多） - 圈的个数越少越好（项数越少） - 每个圈至少包含一个未被其他圈覆盖的1 - 可以重复覆盖
合并规律： - 2个相邻 → 消去1个因子 - 4个相邻 → 消去2个因子 - 8个相邻 → 消去3个因子

1.3 逻辑门电路
一、分立元件逻辑门
1. 二极管门电路
与门：二极管串联，全1出1，有0出0
或门：二极管并联，有1出1，全0出0
2. 三极管非门
输入高电平 → 三极管导通 → 输出低电平
输入低电平 → 三极管截止 → 输出高电平
二、CMOS集成逻辑门
1. MOS管工作原理
NMOS：G和S加高电平，D和S导通（N管高电平导通）
PMOS：G和S加低电平，D和S导通（P管低电平导通）
2. CMOS反相器（非门）
由一个PMOS和一个NMOS组成
输入低电平：P管导通，N管截止，输出高电平
输入高电平：N管导通，P管截止，输出低电平
特点：静态功耗几乎为0
3. CMOS门电路结构规律
口诀：上并下串是与非，上串下并是或非
4. CMOS传输门
由一对PMOS和NMOS并联组成
控制信号cn=0,c=1时导通，可以双向传输信号
三、TTL集成逻辑门
1. TTL与非门
采用多发射极晶体管实现与逻辑
速度比CMOS快，但功耗大
2. 集电极开路门（OC门）和漏极开路门（OD门）
特点：输出级集电极/漏极是开路的，必须外接上拉电阻
用途：
实现线与功能
电平转换
驱动大电流负载
3. 三态门（TS门）
三种输出状态：高电平、低电平、高阻态
控制方式：通过使能端EN控制
主要用途：总线接口、数据双向传输

1.4 触发器
一、触发器概述
触发器是数字电路里的”记忆单元”，能存住1位二进制信息（0或1）。跟组合电路不一样，它的输出不光看当前输入，还跟之前的状态有关。
二、触发器的发展脉络
基本RS → 钟控RS → 钟控D → 主从RS → 主从JK → 边沿D/JK
  ↓         ↓        ↓        ↓         ↓         ↓
无时钟   有空翻   有空翻   无空翻   一次翻转   性能最优
有约束   有约束   无约束   有约束   无约束    无约束
三、各种触发器详解
1. 基本RS触发器
注意：SD和RD不能同时为0！
2. 钟控RS触发器
加了个时钟控制门，只有CP=1时输入才有效
问题：CP=1期间，如果输入变化，输出会跟着变，这叫空翻
3. 钟控D触发器
只有一个输入端D，解决了约束问题
特性：Q^(n+1) = D（CP=1时）
还是有空翻问题！
4. 主从触发器
核心思想：分两步走，彻底消除空翻！
CP=1期间：主触发器接收信号，从触发器保持不动
CP下降沿：主触发器状态一次性传给从触发器
5. 边沿触发器（性能最优）
只在时钟的上升沿或下降沿那一瞬间触发。
四、两个重要概念
1. 空翻（Race-around）
定义：同一个时钟脉冲期间，触发器状态连续多次翻转。
发生在：钟控RS、钟控JK这类电平触发触发器。
解决办法：用主从结构或边沿触发器。
2. 一次翻转（One-time Flip）
定义：CP=1期间，如果J、K信号多次变化，主触发器最多只翻转一次。
发生在：主从JK触发器。
解决办法：用边沿JK触发器。

3.1 基本描述方式

module h_adder(A, B, SO, CO);
    input A, B;
    output SO, CO;
    assign SO = A ^ B;    // 异或逻辑
    assign CO = A & B;    // 与逻辑

（2）always过程语句（行为描述）
module MUX41a(a, b, c, d, s1, s0, y);
    input a, b, c, d, s1, s0;
    output y;
    reg y;
    
    always @(a or b or c or d or s1 or s0)
        case({s1, s0})
            2'b00: y <= a;
            2'b01: y <= b;
            2'b10: y <= c;
            2'b11: y <= d;
            default: y <= a;
        endcase
endmodule

四、时序逻辑电路Verilog设计
4.1 基本时序元件
（1）D触发器（边沿触发）
module DFF1(CLK, D, Q);
    output Q;
    input CLK, D;
    reg Q;
    
    always @(posedge CLK)    // CLK上升沿启动
        Q <= D;               // CLK有上升沿时，D被锁入Q
endmodule
（2）含异步复位和时钟使能的D触发器
module DFF2(CLK, D, Q, RST, EN);
    output Q;
    input CLK, D, RST, EN;
    reg Q;
    
    always @(posedge CLK or negedge RST) begin
        if (!RST) Q <= 0;      // 异步复位
        else if (EN) Q <= D;   // 时钟使能
    end
endmodule
（3）锁存器（电平触发）
module LATCH1(CLK, D, Q);
    output Q;
    input CLK, D;
    reg Q;
    
    always @(D or CLK)
        if (CLK) Q <= D;    // CLK为高电平时，Q随D改变
endmodule
注意：if没有else会导致锁存器生成
4.2 敏感信号表规则
重要规则： - 敏感信号表中不允许出现混合信号（一旦含有posedge/negedge，其他普通变量不能放入） - 若定义某变量为异步电平敏感信号，则在if条件句中应该对敏感信号表中的信号有匹配的表述 - 非复位或置位的独立于时钟的信号只能在其他过程中定义
4.3 计数器设计
4位二进制计数器
module CNT4(CLK, Q);
    output [3:0] Q;
    input CLK;
    reg [3:0] Q;
    
    always @(posedge CLK)
        Q <= Q + 1;
endmodule
异步复位同步计数使能可预置型十进制计数器
module CNT10(CLK, RST, EN, LOAD, COUT, DOUT, DATA);
    input CLK, EN, RST, LOAD;
    input [3:0] DATA;
    output [3:0] DOUT;
    output COUT;
    reg [3:0] Q1;
    reg COUT;
    
    assign DOUT = Q1;
    
    always @(posedge CLK or negedge RST) begin    // 时序过程
        if (!RST) Q1 <= 0;                         // 异步清0
        else if (EN) begin                         // 同步使能
            if (!LOAD) Q1 <= DATA;                 // 同步加载
            else if (Q1 < 9) Q1 <= Q1 + 1;
            else Q1 <= 4'b0000;
        end
    end
    
    always @(Q1)                                   // 组合过程
        if (Q1 == 4'h9) COUT = 1'b1;
        else COUT = 1'b0;
endmodule
4.4 移位寄存器
8位并行输入串行输出移位寄存器
module SHFT1(CLK, LOAD, DIN, QB);
    output QB;
    input CLK, LOAD;
    input [7:0] DIN;
    reg [7:0] REG8;
    
    always @(posedge CLK)
        if (LOAD) REG8 <= DIN;
        else REG8[6:0] <= REG8[7:1];    // 右移
    
    assign QB = REG8[0];
endmodule

五、有限状态机（FSM）设计
5.1 状态机结构
最常用的状态机结构包含： 1. 说明部分：状态转换变量的定义和所有可能状态的说明 2. 主控时序过程：负责状态机运转和在时钟驱动下负责状态转换 3. 主控组合过程：根据当前状态和外部信号发出控制信号，确定下一状态走向 4. 辅助过程：配合状态机工作的组合过程或时序过程
5.2 状态机模板
module FSM_EXP(clk, reset, state_inputs, comb_outputs);
    input clk;
    input reset;
    input [0:1] state_inputs;
    output [3:0] comb_outputs;
    reg [3:0] comb_outputs;
    
    parameter s0=0, s1=1, s2=2, s3=3, s4=4;    // 定义状态参数
    reg [4:0] c_st, next_state;                 // 现态和次态变量
    
    // 主控时序过程
    always @(posedge clk or negedge reset) begin
        if (!reset) c_st <= s0;                 // 复位有效时进入初态
        else c_st <= next_state;
    end
    
    // 主控组合过程
    always @(c_st or state_inputs) begin
        case (c_st)
            s0: begin
                comb_outputs <= 5;
                if (state_inputs == 2'b00) next_state <= s0;
                else next_state <= s1;
            end
            s1: begin
                comb_outputs <= 8;
                if (state_inputs == 2'b01) next_state <= s1;
                else next_state <= s2;
            end
            // ... 其他状态
            default: next_state <= s0;
        endcase
    end
endmodule

核心思路： 1. 采用同步设计（最推荐）：利用触发器对信号进行”打拍”（采样） 2. 引入选通/锁存信号：信号完全稳定后才打开选通门 3. 逻辑设计优化：卡诺图增加圈避免相切，改用格雷码计数器 4. 硬件滤波：输出端并联小电容
Verilog中打两拍消除毛刺：
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        din_r1 <= 1'b0;
        dout   <= 1'b0;
    end else begin
        din_r1 <= din;      // 第一拍：可能采到毛刺
        dout   <= din_r1;   // 第二拍：过滤毛刺，输出稳定信号
    end
end

    input  [3:0] B,        // 4位操作数B
    input        M,        // 控制信号：0=加法，1=减法
    output [3:0] S,        // 运算结果
    output       Cout,     // 进位/借位输出
    output       Overflow  // 溢出标志
);

wire [3:0] B_xor;      // B经过异或门后的值
wire [4:0] Sum;        // 5位和（含进位）

// B的取反控制
assign B_xor = B ^ {4{M}};  // M=0时B_xor=B，M=1时B_xor=~B

// 加法运算（包含补码减法）
assign Sum = A + B_xor + M;

// 输出赋值
assign S = Sum[3:0];
assign Cout = Sum[4];

// 溢出判断
// 对于加法（M=0）：A、B同号，结果与A异号时溢出
// 对于减法（M=1）：A、~B同号，结果与A异号时溢出
assign Overflow = (A[3] == B_xor[3]) && (S[3] != A[3]);

endmodule
