快速排序原理

快速排序是一种高效的排序算法，采用分治策略：

1. 选择基准值

从数组中选择一个元素作为"基准"（pivot），通常选择第一个、最后一个或中间的元素。

2. 分区操作

重新排列数组，所有比基准小的元素放在左边，比基准大的元素放在右边。基准元素位于最终位置。

3. 递归排序

对基准左右两边的子数组分别递归应用快速排序。

时间复杂度

平均情况: O(n log n)
最坏情况: O(n²) | 最好情况: O(n log n)
